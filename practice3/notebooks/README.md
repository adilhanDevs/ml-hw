# Практическая работа №3 — Обработка пропусков

## Выбранная стратегия

Для заполнения пропущенных значений в числовых столбцах датасета по странам мира я выбрал **медиану** (`median`). Пропуски в каждом столбце заменяются медианой этого же столбца.

## Обоснование выбора

Страны существенно различаются по площади и численности населения. Очень большие значения этих показателей у отдельных стран могут заметно смещать среднее арифметическое.

- **Медиана устойчива к выбросам** и меньше зависит от крайних значений.
- **Она подходит для асимметричных распределений**, когда большинство значений относительно невелики, а несколько — значительно выше остальных.
- **Единая стратегия** упрощает обработку пропусков в числовых признаках.

> Большие значения не обязательно являются ошибками: они могут отражать реальные особенности стран.
