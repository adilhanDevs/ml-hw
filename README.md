# Проектирование операционных систем

Репозиторий с домашними и практическими заданиями по предмету
**«Проектирование операционных систем»**.

## Содержание

| Папка | Описание |
|---|---|
| [practice1](practice1) | Практическая работа №1: анализ данных в Jupyter Notebook (pandas, matplotlib) |

## Требования

- Python 3.10+
- Jupyter Notebook / JupyterLab
- pandas, numpy, matplotlib, scikit-learn

## Установка

Склонируйте репозиторий:

```bash
git clone https://github.com/adilhanDevs/ml-hw
cd ml
```

Создайте и активируйте виртуальное окружение:

```bash
python3 -m venv venv
source venv/bin/activate
```

Установите зависимости:

```bash
pip install jupyterlab pandas numpy matplotlib scikit-learn
```

## Запуск

Запустите Jupyter Lab:

```bash
jupyter lab
```

Откроется браузер — перейдите в нужную папку с практикой (например,
[practice1/notebooks/practice1.ipynb](practice1/notebooks/practice1.ipynb))
и запускайте ячейки по порядку (`Shift + Enter`).
